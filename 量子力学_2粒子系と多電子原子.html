02

2粒子系の量子力学

2.1 多粒子系の広がりと物理的背景

自然界において、単一の粒子のみで構成される孤立系は極めて稀であり、多くの物理現象は複数の粒子が相互作用する「多粒子系」として記述されます。多粒子系はミクロからマクロまで様々なスケールで現れます：

  • 原子系：水素原子（電子 \(e\) と量子核／プロトン \(p\)）、重水素核（プロトン \(p\) と中性子 \(n\)）
  • 分子系：水素分子 \(H_2\)、一酸化炭素分子 \(CO\) など
  • 素粒子の束縛状態：ポジトロニウム（電子 \(e^-\) と陽電子 \(e^+\) の束縛系）、クォーコニウム（クォークと反クォークの束縛状態）

2.2 2粒子系の状態ケットと波動関数

まず「状態ケット」と「波動関数」って何？

量子力学では、粒子がどこにいるかを1つの数字で言い切ることができません。その代わりに、「位置 \(x\) に粒子を見出す確率の度合い」を表す関数 \(\psi(x,t)\)（波動関数）を使います。 \(|x\rangle\) は「粒子がちょうど位置 \(x\) にいる」という理想的な状態を表す記号（ケット）です。実際の粒子の状態 \(|\psi\rangle\) は、あらゆる位置の \(|x\rangle\) を、重み \(\psi(x,t)\) をつけて足し合わせた（積分した）ものだと考えます。積分記号 \(\int dx\) はまさに「全ての \(x\) について足し合わせる」という操作です。

1次元1粒子（スピンなし）の場合、状態ケット \(|\psi\rangle\) は位置固有状態 \(|x\rangle\) を基底として、次のように展開されました。

\[ |\psi\rangle = \int dx\, \psi(x,t)\, |x\rangle \]

これに対し、3次元空間に存在する2つの粒子（粒子1、粒子2）からなる系を考えます。粒子1の位置を \(r_1\)、スピン状態を \(\sigma_1\)、粒子2の位置を \(r_2\)、スピン状態を \(\sigma_2\) とすると、系の同時固有状態（固有ケット）はテンソル積を用いて次のように表されます：

\[ |r_1,\sigma_1;\, r_2,\sigma_2\rangle = |r_1,\sigma_1\rangle_1 \otimes |r_2,\sigma_2\rangle_2 \]
この式は何を言っている？

右辺の \(\otimes\)（テンソル積）は「2つの独立な情報をペアにして1つの状態として扱う」という意味です。日常的な例で言えば、ある人の「身長」と「体重」は別々の量ですが、「（身長, 体重）」という組にしてしまえば1つのデータとして扱えます。ここでも同様に、「粒子1がどこで、どのスピンか」という情報と「粒子2がどこで、どのスピンか」という情報を組み合わせて、1つの2粒子状態 \(|r_1,\sigma_1;r_2,\sigma_2\rangle\) を作っています。左辺の \(;\)（セミコロン）は、この2つの情報が1つの状態として結びついていることを示す表記です。

したがって、2粒子系の全状態ケット \(|\Psi\rangle\) は、位置座標に関する3重積分およびスピンの和をとることで次のように展開されます：

\[ |\Psi\rangle = \sum_{\sigma_1,\sigma_2} \iint d^3r_1\, d^3r_2\; \Psi(r_1,\sigma_1,r_2,\sigma_2,t)\, |r_1,\sigma_1;\, r_2,\sigma_2\rangle \]

ここで、展開係数 \(\Psi(r_1,\sigma_1,r_2,\sigma_2,t)\) が2粒子系の全波動関数です。

直感的なイメージ：地図が2枚必要になる

1粒子の波動関数 \(\psi(x,t)\) は、1本の数直線（または3次元空間）上の「濃淡地図」だとイメージできます。濃い場所ほど、その位置に粒子を見出す確率が高いという意味です。 2粒子系の波動関数 \(\Psi(r_1,\sigma_1,r_2,\sigma_2,t)\) はこれよりずっと複雑で、「粒子1がここにいて、同時に粒子2がそこにいる確率の濃淡」を表す地図になります。つまり、3次元空間の地図を2枚重ねるのではなく、6次元（\(r_1\) の3成分 + \(r_2\) の3成分）の地図が必要になるということです。これが2粒子系を1粒子系よりも複雑にしている根本的な理由です。

補足：テンソル積は何をしている？

粒子1の状態と粒子2の状態を「同時に指定する」ための数学的な書き方です。1粒子なら \(|r\rangle\) だけでよいのに対し、2粒子では「粒子1がどこにいるか」と「粒子2がどこにいるか」を同時に扱う必要があります。そのため、2つの状態を組み合わせたテンソル積を使います。

2.3 2粒子系の時間依存Schrödinger方程式

簡単のため、スピン依存性を一旦省略し、空間座標のみに依存する2粒子系を考えます。質量 \(m_1\) の粒子1と質量 \(m_2\) の粒子2がポテンシャル \(V(r_1,r_2)\) のもとで運動しているとき、系の時間依存Schrödinger方程式は

\[ i\hbar \frac{\partial \Psi}{\partial t} = \left[ -\frac{\hbar^2}{2m_1}\nabla_1^2 -\frac{\hbar^2}{2m_2}\nabla_2^2 + V(r_1,r_2) \right] \Psi \]

ここで、\(\nabla_1^2\) および \(\nabla_2^2\) は、それぞれ粒子1の座標 \(r_1=(x_1,y_1,z_1)\) および粒子2の座標 \(r_2=(x_2,y_2,z_2)\) のみに作用するラプラシアン（2階偏微分演算子）です。

式の読み方

左辺は「波動関数が時間とともにどう変化するか」を表します。右辺の最初の2項はそれぞれ粒子1・粒子2の運動エネルギー、最後の \(V\) は2粒子に関係するポテンシャルエネルギーです。つまり、2粒子問題では運動エネルギーが2つ現れる点が1粒子問題との大きな違いです。

記号の意味をひとつずつ確認しよう

\(i\hbar\dfrac{\partial\Psi}{\partial t}\)：波動関数 \(\Psi\) が時間 \(t\) とともにどれだけ・どのように変化するかを表す項です。\(\hbar\)（エイチバー）はプランク定数を \(2\pi\) で割った定数で、量子効果の大きさを決める基本定数です。

\(-\dfrac{\hbar^2}{2m_1}\nabla_1^2\)：粒子1の運動エネルギーに対応する演算子です。\(\nabla_1^2\)（ラプラシアン）は「その場所で波動関数がどれだけ急に曲がっているか」を測る微分演算子で、波動関数の曲がり具合が運動エネルギーの大きさに対応します。粒子2についても同様の項があります。

\(V(r_1,r_2)\)：2つの粒子の位置関係によって決まるポテンシャルエネルギー、たとえば静電気的な引力や斥力です。

この方程式全体が言っていることを一言でまとめると、「波動関数の時間変化は、運動エネルギーとポテンシャルエネルギーの和（ハミルトニアン）によって決まる」ということです。これは1粒子でも2粒子でも変わらない、量子力学の基本原理です。

2.4 重心座標と相対座標への変換（微分計算の全過程）

この節でやろうとしていることの全体像

2粒子系のSchrödinger方程式は、\(r_1\) と \(r_2\) という2つの独立な変数を含んでおり、このままでは解くのが大変です。ところが、日常の物理現象を思い出すと、2つの物体が互いに力を及ぼし合っているとき、「2物体全体の重心がどう動くか」と「2物体が互いにどれだけ離れてどう向き合っているか」を別々に考えると、問題がとてもシンプルになることがあります（たとえば連星や、バネでつながった2つのおもりの運動）。 この節では、その考え方を量子力学のSchrödinger方程式に適用し、\(r_1,r_2\) という変数の組を、重心座標 \(R\) と相対座標 \(r\) という新しい変数の組に置き換える計算を、省略せずに追っていきます。

2つの粒子が互いに及ぼし合う力（ポテンシャル）が両者の相対位置関係のみに依存する場合、粒子を個別に扱うよりも重心座標（Center-of-Mass Coordinates）\(R\) と相対座標（Relative Coordinates）\(r\) に変換する方が格段に解析しやすくなります。

\[ R = \frac{m_1 r_1 + m_2 r_2}{m_1+m_2} \equiv (X,Y,Z) \] \[ r = r_1 - r_2 \equiv (x,y,z) \]
重心座標 R と相対座標 r のイメージ

\(R\) は「2つの粒子を1つの塊とみなしたときの、その塊全体の位置（重心）」です。質量が重い方の粒子に近い位置に重心が来ることに注意してください（式の分子で \(m_1,m_2\) が重みとしてかかっています）。 一方 \(r\) は「粒子1から見て粒子2がどちらの方向にどれだけ離れているか」を表す、2粒子間の相対的な位置ベクトルです。たとえば、地球と月の系で考えると、\(R\) は地球と月をまとめた重心の位置（実はほぼ地球の中心に近い場所です）、\(r\) は地球から見た月の相対的な位置になります。

【1次元における微分演算子の変換導出】

以下では、まず1次元（\(x\)方向）だけに着目して、\(x_1,x_2\) についての微分を \(X,x\) についての微分に書き換える計算を、途中式を省略せずに行います。天下り的に結果だけを覚えるのではなく、「なぜクロス項が消えるのか」を実際に手を動かして確認することがこの節の目的です。

\(x\)成分のみに着目して、偏微分の連鎖律（Chain Rule）を用いて計算過程を途切れることなく書き下します。1次元での関係式は以下の通りです：

\[ X = \frac{m_1 x_1 + m_2 x_2}{m_1+m_2}, \qquad x = x_1-x_2 \]

各変数での偏微分を求めます：

\[ \frac{\partial X}{\partial x_1} = \frac{m_1}{m_1+m_2}, \quad \frac{\partial x}{\partial x_1} = 1 \] \[ \frac{\partial X}{\partial x_2} = \frac{m_2}{m_1+m_2}, \quad \frac{\partial x}{\partial x_2} = -1 \]
連鎖律（Chain Rule）とは？

\(\Psi\) はもともと \(x_1,x_2\) の関数ですが、新しい変数 \(X,x\) を使って表し直したいとします。このとき、\(\Psi\) を \(x_1\) で微分するには、「\(x_1\) が変化すると \(X\) も \(x\) も両方変化する」ことを考慮しなければなりません。これが連鎖律で、 \(\dfrac{\partial \Psi}{\partial x_1} = \dfrac{\partial X}{\partial x_1}\dfrac{\partial \Psi}{\partial X} + \dfrac{\partial x}{\partial x_1}\dfrac{\partial \Psi}{\partial x}\) という形になります。上で求めた \(\dfrac{\partial X}{\partial x_1}\) や \(\dfrac{\partial x}{\partial x_1}\) の値を、この連鎖律の式に代入していく、というのがこれから行う計算です。

【1】粒子1に関する1階および2階偏微分

\[ \frac{\partial \Psi}{\partial x_1} = \frac{\partial X}{\partial x_1}\frac{\partial \Psi}{\partial X} + \frac{\partial x}{\partial x_1}\frac{\partial \Psi}{\partial x} = \frac{m_1}{m_1+m_2}\frac{\partial \Psi}{\partial X} + \frac{\partial \Psi}{\partial x} \]

これをもう一度 \(x_1\) で微分すると：

\[ \frac{\partial^2 \Psi}{\partial x_1^2} = \frac{m_1^2}{(m_1+m_2)^2}\frac{\partial^2 \Psi}{\partial X^2} + \frac{2m_1}{m_1+m_2}\frac{\partial^2 \Psi}{\partial X \partial x} + \frac{\partial^2 \Psi}{\partial x^2} \]

【2】粒子2に関する1階および2階偏微分

\[ \frac{\partial \Psi}{\partial x_2} = \frac{m_2}{m_1+m_2}\frac{\partial \Psi}{\partial X} - \frac{\partial \Psi}{\partial x} \]

これをもう一度 \(x_2\) で微分すると：

\[ \frac{\partial^2 \Psi}{\partial x_2^2} = \frac{m_2^2}{(m_1+m_2)^2}\frac{\partial^2 \Psi}{\partial X^2} - \frac{2m_2}{m_1+m_2}\frac{\partial^2 \Psi}{\partial X \partial x} + \frac{\partial^2 \Psi}{\partial x^2} \]

【3】運動エネルギー項（ラプラシアン項）の合成

Schrödinger方程式の中にある運動エネルギーの和を計算します。カッコ内の項に注目して、次を足し合わせます：

\[ \frac{1}{m_1}\frac{\partial^2\Psi}{\partial x_1^2} + \frac{1}{m_2}\frac{\partial^2\Psi}{\partial x_2^2} \] \[ = \left[\frac{m_1}{(m_1+m_2)^2} + \frac{m_2}{(m_1+m_2)^2}\right]\frac{\partial^2\Psi}{\partial X^2} + \left[\frac{2}{m_1+m_2} - \frac{2}{m_1+m_2}\right]\frac{\partial^2\Psi}{\partial X \partial x} + \left(\frac{1}{m_1}+\frac{1}{m_2}\right)\frac{\partial^2\Psi}{\partial x^2} \]

ここで、クロス項 \(\left(\dfrac{\partial^2\Psi}{\partial X \partial x}\right)\) の係数は \(\dfrac{2}{m_1+m_2} - \dfrac{2}{m_1+m_2} = 0\) となって完全に相殺消滅します。また、第1項の係数は \(\dfrac{m_1+m_2}{(m_1+m_2)^2} = \dfrac{1}{m_1+m_2} = \dfrac{1}{M}\) となります。

なぜ「クロス項が消える」ことがそんなに重要なのか

クロス項 \(\dfrac{\partial^2\Psi}{\partial X \partial x}\) は、「重心の位置 \(X\) と相対位置 \(x\) の両方に同時に関係する」項です。もしこの項が残っていたら、重心の運動と相対運動が数式の上で絡み合ったままになり、方程式を「重心だけの問題」と「相対運動だけの問題」に分けることができません。 ここで偶然にも \(\dfrac{2}{m_1+m_2}\) と \(-\dfrac{2}{m_1+m_2}\) がちょうど打ち消し合うため、クロス項がきれいに消えます。これは単なる数式のテクニックではなく、「質量に反比例する重みで運動エネルギーを足し合わせる」という組み合わせ方（つまり \(\frac{1}{m_1}\partial_{x_1}^2+\frac{1}{m_2}\partial_{x_2}^2\) という形）を選んだからこそ起きる、この座標変換に特有のうまい性質です。

ここで全質量 \(M\) および換算質量（Reduced Mass）\(m\) を次のように定義します：

\[ M \equiv m_1 + m_2 \] \[ m \equiv \left(\frac{1}{m_1} + \frac{1}{m_2}\right)^{-1} = \frac{m_1 m_2}{m_1+m_2} \]
換算質量 m の直感的な意味

換算質量 \(m\) は、2つの質量 \(m_1,m_2\) を「1つの実効的な質量」にまとめたものです。面白い性質として、もし \(m_1\) が \(m_2\) よりずっと大きい場合（\(m_1\gg m_2\)）、\(m \approx m_2\) となり、軽い方の粒子の質量にほぼ等しくなります。これは直感とも合っています。重い物体（たとえば地球）はほとんど動かず、軽い物体（たとえばボール）だけが実質的に運動しているように見えるからです。この性質は、後で水素原子（電子と陽子）に適用するときに重要な役割を果たします。

したがって、3次元全空間における運動エネルギー演算子は次のように重心と相対運動に完全に分離されます：

\[ -\frac{\hbar^2}{2m_1}\nabla_1^2 - \frac{\hbar^2}{2m_2}\nabla_2^2 = -\frac{\hbar^2}{2M}\nabla_R^2 - \frac{\hbar^2}{2m}\nabla_r^2 \]

ここで、\(\nabla_R^2 = \dfrac{\partial^2}{\partial X^2} + \dfrac{\partial^2}{\partial Y^2} + \dfrac{\partial^2}{\partial Z^2}\)、\(\nabla_r^2 = \dfrac{\partial^2}{\partial x^2} + \dfrac{\partial^2}{\partial y^2} + \dfrac{\partial^2}{\partial z^2}\) です。これより、重心・相対座標で表記したSchrödinger方程式が得られます：

\[ i\hbar\frac{\partial \Psi}{\partial t} = \left[-\frac{\hbar^2}{2M}\nabla_R^2 - \frac{\hbar^2}{2m}\nabla_r^2 + V(R,r)\right] \Psi(R,r,t) \]
ここが重要

「粒子1の運動」と「粒子2の運動」をそのまま追いかける代わりに、「2粒子全体の重心が動く運動」と「2粒子同士の距離・向きが変わる相対運動」に分けました。クロス項が消えることが、この変換が非常に便利な理由です。

言い換えれば、もとの方程式は \(r_1,r_2\) という2つの3次元変数（合計6次元）が複雑に絡み合った1つの偏微分方程式でしたが、変換後は「\(R\) だけに関する方程式」と「\(r\) だけに関する方程式」という、互いに独立した2つのシンプルな問題に分解できる見通しが立ちました。次節でこれを実際に完全に分離します。

2.5 相互作用ポテンシャルが相対座標のみに依存する場合（変数分離）

ポテンシャルが2粒子の相対距離のみに依存する形 \(V=V(r)\)（例えばクーロン力のように重心位置 \(R\) に依存しない場合）をとるとき、全波動関数を次のように変数分離できます：

\[ \Psi(R,r,t) = U(R)\,u(r)\,e^{-iEt/\hbar} \]
この「積の形」を仮定する理由

\(\Psi(R,r,t)\) を \(U(R)\)（重心の位置だけの関数）、\(u(r)\)（相対位置だけの関数）、\(e^{-iEt/\hbar}\)（時間だけの関数）の3つの積として書けると仮定します。これは「とりあえずそう置いてみて、うまくいくか確かめる」という、微分方程式を解くときによく使われる標準的な手法（変数分離法）です。時間部分を \(e^{-iEt/\hbar}\) という特定の形にするのは、Schrödinger方程式の左辺 \(i\hbar\partial\Psi/\partial t\) にこの形を代入すると、ちょうど \(E\Psi\) という単純な形が出てくるように選んであるためです（実際、\(i\hbar\dfrac{\partial}{\partial t}e^{-iEt/\hbar} = E\,e^{-iEt/\hbar}\) となります）。この仮定が正しいかどうかは、実際に代入して矛盾が起きないことを確認することで検証されます。

ここで \(E\) は系の全エネルギーです。これを時間依存Schrödinger方程式に代入して両辺を \(e^{-iEt/\hbar}\) で割ると、時間に依存しないSchrödinger方程式が得られます：

\[ E\, U(R)u(r) = \left[-\frac{\hbar^2}{2M}\nabla_R^2 -\frac{\hbar^2}{2m}\nabla_r^2 + V(r)\right]U(R)u(r) \]

微分をそれぞれ適用すると：

\[ E\,Uu = -\frac{\hbar^2}{2M}(\nabla_R^2 U)u -\frac{\hbar^2}{2m}(\nabla_r^2 u)U + V(r)Uu \]

両辺を \(U(R)u(r)\) で割ると：

\[ E = -\frac{\hbar^2}{2M}\frac{\nabla_R^2 U}{U} -\frac{\hbar^2}{2m}\frac{\nabla_r^2 u}{u} + V(r) \] \[ \Leftrightarrow \frac{\hbar^2}{2M}\frac{\nabla_R^2 U}{U} = -\frac{\hbar^2}{2m}\frac{\nabla_r^2 u}{u} + V(r) - E \]
「両辺が定数でなければならない」というロジック

これは変数分離法の最も重要な論理的ステップです。左辺は \(R\) だけの関数、右辺は \(r\) だけの関数なので、もし \(R\) をそのままにして \(r\) だけを少し動かしたら、右辺の値は変わるかもしれませんが、左辺の値は \(R\) を動かしていないので変わりません。両辺は常に等しくなければならないので、右辺が \(r\) を動かしても値が変わってはいけない、つまり右辺は \(r\) によらない「定数」でなければならないのです。同じ理屈で左辺も \(R\) によらない定数でなければなりません。結局、左辺と右辺は共通の1つの定数に等しくなります。

この等式の左辺は重心座標 \(R\) のみの関数であり、右辺は相対座標 \(r\) のみの関数です。両者が任意の \(R,r\) で常に等しくなるためには、両辺が共通の定数に等しくなければなりません。この分離定数を \(-E_R\)（\(E_R\) は重心運動のエネルギー）とおくと、2つの方程式に完全に独立分離されます：

\[ ① \quad -\frac{\hbar^2}{2M}\nabla_R^2 U(R) = E_R\, U(R) \] \[ ② \quad \left[-\frac{\hbar^2}{2m}\nabla_r^2 + V(r)\right]u(r) = E_r\, u(r) \] \[ E = E_R + E_r \]
補足：変数分離とは？

1つの難しい式を、別々の変数だけを含む複数の簡単な式に分解する操作です。この場合、「重心だけの問題」と「2粒子間の相対運動だけの問題」に分けられます。最終的に全エネルギーは、重心運動のエネルギーと相対運動のエネルギーの和になります。

2.6 重心運動の解とデルタ関数規格化

「自由粒子」とはどういう意味か

重心運動の方程式にはポテンシャル項 \(V\) が含まれていません。これは、重心 \(R\) の運動には外力が一切働かない（力を受けるのは相対座標 \(r\) の方だけ）ということを意味します。力を受けずに空間を自由に動き回る粒子のことを「自由粒子」と呼びます。物理的なイメージとしては、2つの粒子が互いに引っ張り合ったり反発し合ったりしていても、系全体としての重心は、外から力を受けない限り、まっすぐ等速で進み続ける（あるいは静止し続ける）ということです。これは古典力学における「重心の運動方程式には内力が現れない」という事実の量子力学版です。

重心運動の方程式 \(\nabla_R^2 U(R) = -\dfrac{2ME_R}{\hbar^2}U(R)\) は、全質量 \(M\) の自由粒子（Free Particle）のSchrödinger方程式そのものです。その解は平面波解として次のように与えられます：

\[ U(R) = N_U\, e^{iK\cdot R}, \qquad K=(K_x,K_y,K_z), \qquad |K|=\frac{\sqrt{2ME_R}}{\hbar} \]
規格化とデルタ関数規格化の違い

通常、波動関数は「全空間で積分すると1になる」ように規格化します（粒子がどこかに存在する確率は100%だから）。しかし、平面波 \(e^{iK\cdot R}\) は空間全体に一様に広がっており、その絶対値の2乗を全空間で積分すると無限大に発散してしまいます。これは、平面波が「運動量が完全に確定した状態」という理想化された（実際には作れない）状態を表しているためです。 この問題を回避するために、通常の「1に規格化する」代わりに、「異なる \(K\) の波同士は直交し、同じ \(K\) 同士では無限大になる」という性質をディラックのデルタ関数 \(\delta^3(K-K')\) を使って表現します。これが「デルタ関数規格化」です。

ここで \(N_U\) は規格化定数です。自由粒子の波動関数は全空間で積分すると発散するため、ディラックのデルタ関数規格化（Dirac Delta Normalization）を行います：

\[ \int d^3R\; U_{K'}^{*}(R)\,U_K(R) = \delta^3(K-K') \]

左辺に平面波解を代入して計算を進めます：

\[ |N_U|^2 \iiint dX\,dY\,dZ\; e^{i(K-K')\cdot R} = |N_U|^2 (2\pi)^3 \delta^3(K-K') \]

ここで1次元のフーリエ変換の性質 \(\displaystyle\int_{-\infty}^{\infty} dx\, e^{i(k-k')x} = 2\pi\delta(k-k')\) を3次元に拡張した公式を用いています。

これが \(\delta^3(K-K')\) と等しくなることから、規格化定数 \(N_U\) は以下のように決定されます：

\[ |N_U|^2(2\pi)^3 = 1 \quad \Rightarrow \quad N_U = (2\pi)^{-3/2} \]

水素原子への適用と換算質量

一方、相対運動の方程式 \(\left[-\dfrac{\hbar^2}{2m}\nabla_r^2+V(r)\right]u(r)=E_r\,u(r)\) は、まさに質量 \(m\) の粒子が中心力ポテンシャル \(V(r)\) から受ける運動を表します。例えば水素原子の場合、粒子1を電子（質量 \(m_e\)）、粒子2を陽子（質量 \(m_p\)）と置くと、換算質量 \(m\) は：

\[ m = \frac{m_e m_p}{m_e+m_p} = \frac{m_e}{1+m_e/m_p} \]

陽子の質量は電子の約1836倍（\(m_p \approx 1836\,m_e\)）であるため、\(m_e/m_p \ll 1\) であり、\(m \approx m_e\) と近似できます。つまり、原子核が固定されているとみなす極限は、換算質量 \(m\) を用いることで厳密に扱われていることが分かります。

補足：なぜ「換算質量」が便利なのか

水素原子は本当は電子だけが動いているのではなく、電子と陽子の両方が動いています。換算質量を使うと、その2体問題を「質量 \(m\) の1粒子が中心力ポテンシャル中を動く問題」として書けます。これが水素原子のSchrödinger方程式を解きやすくする重要な一歩です。

同種粒子とPauliの排他原理

3.1 古典力学と量子力学における同種粒子の本質的違い

質量、電荷、スピンなどの固有の性質が全く同じである粒子を「同種粒子（Identical Particles）」と呼びます（例：2つの電子）。

  • 古典力学：各粒子の位置と運動量を連続的に追跡（軌跡の追跡）できるため、粒子Aと粒子Bを常に区別（Distinguishable）することが可能です。
  • 量子力学：不確定性原理により明確な「軌跡」が存在せず、波動関数の広がりが重なり合うため、2つの同種粒子を区別すること（Indistinguishable）は原理的に不可能です。
補足：同種粒子で「ラベル」を交換するとは？

2個の電子に「電子1」「電子2」と番号を付けても、それは数学上の整理のための番号です。電子1と電子2に固有の名札が付いているわけではありません。そのため、2粒子を入れ替えた記述と、入れ替える前の記述は物理的に同じ系を表さなければなりません。

3.2 状態の入れ替え演算子と固有値（ボソンとフェルミオン）

2つの同種粒子の座標とスピンを全交換する「入れ替え演算子 \(\hat P_{12}\)」を導入します。入れ替えを行っても、粒子が区別できない以上、観測される物理的な状態（確率密度 \(|\Psi|^2\)）は不変でなければなりません。したがって、入れ替え後の波動関数は元の波動関数の定数 \(c\) 倍となります：

\[ \hat P_{12}\Psi(r_1,\sigma_1;r_2,\sigma_2) = \Psi(r_2,\sigma_2;r_1,\sigma_1) = c\,\Psi(r_1,\sigma_1;r_2,\sigma_2) \]

もう一度入れ替え操作を適用すると、元の状態に完全に戻ります：

\[ \hat P_{12}^2 \Psi = c^2 \Psi = \Psi \quad \Rightarrow \quad c^2=1 \quad \Rightarrow \quad c=\pm 1 \]
なぜ c = ±1 の2択しかないのか

1回粒子を入れ替えると波動関数は \(c\) 倍になります。もう1回（合計2回）入れ替えると、粒子1と粒子2はもとの配置に戻るので、波動関数も完全にもとの \(\Psi\) に戻らなければなりません。式で書けば \(\hat P_{12}(\hat P_{12}\Psi) = \hat P_{12}(c\Psi) = c(c\Psi) = c^2\Psi\) であり、これが \(\Psi\) 自身に等しいので \(c^2=1\) となります。この方程式を満たす実数は \(c=+1\) か \(c=-1\) の2つしかありません。つまり、自然界の同種粒子はこの2択のどちらかに必ず分類される、ということがこの短い計算から導かれます。

相対論的量子力学（スピン統計定理）の重要な結論により、自然界の粒子はスピンの値に応じて以下の2つのグループに大別されます：

  • ① ボソン（Bosons, ボース粒子）：スピンが整数（\(s=0,1,2,\ldots\)）の粒子（光子、ヒッグス粒子、⁴He原子など）。入れ替えに対して波動関数は対称（Symmetric, \(c=+1\)）：\(\Psi(1,2)=+\Psi(2,1)\)
  • ② フェルミオン（Fermions, フェルミ粒子）：スピンが半整数（\(s=1/2,3/2,\ldots\)）の粒子（電子、プロトン、ニュートロン、クォークなど）。入れ替えに対して波動関数は反対称（Antisymmetric, \(c=-1\)）：\(\Psi(1,2)=-\Psi(2,1)\)

3.3 Pauliの排他原理（Pauli Exclusion Principle）の数学的導出

フェルミオン（例えば電子）の反対称性 \(\Psi(r_1,\sigma_1,r_2,\sigma_2)=-\Psi(r_2,\sigma_2,r_1,\sigma_1)\) において、2つの粒子が全く同じ状態（同じ位置 \(r_1=r_2\) かつ同じスピン \(\sigma_1=\sigma_2\)）を占有しようとするとどうなるかを計算します。

両者に同じ状態を代入すると：

\[ \Psi(r_1,\sigma_1;r_1,\sigma_1) = -\Psi(r_1,\sigma_1;r_1,\sigma_1) \]
この計算のトリックを丁寧に見る

反対称性の式 \(\Psi(1,2)=-\Psi(2,1)\) に、「粒子1も粒子2も全く同じ状態にある」という特別な状況（\(r_1=r_2,\ \sigma_1=\sigma_2\)）を当てはめてみます。すると、左辺の \(\Psi(1,2)\) と右辺の \(\Psi(2,1)\) は、もはや区別できる状態同士の入れ替えではなく、「全く同じ値」を指すことになります。つまり、ある数 \(A\)（\(=\Psi(r_1,\sigma_1;r_1,\sigma_1)\)）について \(A=-A\) という方程式が成り立つことになります。これを解くと \(2A=0\)、すなわち \(A=0\) しかありえません。

両辺に \(\Psi(r_1,\sigma_1;r_1,\sigma_1)\) を移項して加えると：

\[ 2\Psi(r_1,\sigma_1;r_1,\sigma_1)=0 \quad \Rightarrow \quad \Psi(r_1,\sigma_1;r_1,\sigma_1)=0 \]

波動関数が恒的に0になるということは、「2個以上のフェルミオンが全く同一の量子状態に入る確率はゼロである」ことを意味します。これがPauliの排他原理の厳密な数学的証明です。一方、ボソンはこのような制限を受けないため、絶対零度付近で多数の粒子が同一の最低エネルギー状態に落ち込むボース＝アインシュタイン凝縮（Bose-Einstein Condensation）を起こすことができます。

なぜこれが「席」の比喩でよく説明されるのか

Pauliの排他原理は、しばしば「1つの椅子には1人しか座れない」という比喩で説明されます。ここでの「椅子」とは量子状態（位置、スピンなどをすべて含めた状態）のことです。ボソンの場合は複数の粒子が同じ「椅子」に何人でも重なって座れますが（実際、レーザー光は膨大な数の光子が同じ状態を占めることで生まれます）、フェルミオンである電子の場合は、数式が示す通り、2個以上が同じ状態を占めようとすると確率がゼロになってしまいます。これが原子の中で電子が同じ軌道に2個までしか入れず（スピンが逆向きのペアまで）、原子ごとに異なる電子配置が生まれる理由であり、ひいては元素の多様な化学的性質のもとになっています。

補足：Pauliの排他原理を一言でいうと

電子のようなフェルミオンでは、2個の粒子が「完全に同じ量子状態」になることが波動関数の反対称性によって禁止されます。重要なのは、単なる経験則として禁止しているのではなく、波動関数を交換したときに \(-1\) 倍になるという性質から数学的に導かれることです。

4.1 空間波動関数とスピン波動関数の分離

電子はスピン \(s=1/2\) を持つフェルミオンです。2つの電子からなる系の全波動関数 \(\Psi\) は、空間波動関数 \(\psi(r_1,r_2)\) とスピン波動関数 \(\chi(\sigma_1,\sigma_2)\) の積として表すことができます：

\[ \Psi(1,2) = \psi(r_1,r_2)\,\chi(\sigma_1,\sigma_2) \]

全波動関数 \(\Psi\) 全体として入れ替え操作 \((1\leftrightarrow 2)\) に対し反対称（\(-1\)倍）でなければなりません。したがって、空間部分とスピン部分の対称性は以下のいずれかの組み合わせに限られます：

  • 空間：対称 (+1) × スピン：反対称 (−1) ＝ 全体：反対称 (−1)
  • 空間：反対称 (−1) × スピン：対称 (+1) ＝ 全体：反対称 (−1)
なぜ「空間部分×スピン部分」に分けて考えられるのか

電子の状態は、「空間のどこにいるか」という情報と「スピンがどちら向きか」という情報の両方を持っています。もしこれらが互いに独立に決まる（つまり相関しない）と仮定できるなら、全体の波動関数はこの2つの積として書けます。粒子の入れ替えは、位置とスピンの両方を同時に入れ替える操作なので、その結果として現れる符号（対称か反対称か）は、空間部分の符号とスピン部分の符号の掛け算になります。全体としては必ず反対称（電子はフェルミオンだから）でなければならないので、「空間が対称でスピンが反対称」か「空間が反対称でスピンが対称」のどちらかしか許されないのです（正×正や負×負では全体が対称になってしまい、条件を満たしません）。

4.2 スピン1重項（Singlet）とスピン3重項（Triplet）

2つのスピン1/2を合成すると、全スピン量子数 \(S=0\)（スピン1重項）および \(S=1\)（スピン3重項）が形成されます。

なぜ「1重項」「3重項」と呼ぶのか

電子1個のスピンは、上向き（\(\alpha\)、\(m_s=+1/2\)）と下向き（\(\beta\)、\(m_s=-1/2\)）の2通りの状態を取り得ます。2個の電子のスピンを合成すると、全部で \(2\times2=4\) 通りの組み合わせが考えられますが、量子力学的に正しく組み合わせると、そのうち1つは全スピン \(S=0\) の状態（状態が1つしかないので「1重項」＝Singlet）、残りの3つは全スピン \(S=1\) の状態（状態が3つあるので「3重項」＝Triplet、\(M_S=+1,0,-1\) に対応）にまとまります。下の表と図は、この4通りの組み合わせの中身を具体的に示しています。

全反対称性を満たすため、空間波動関数の対称性は自動的に決定されます：

  • スピン3重項状態（Triplet）：スピン部分が対称 ⇒ 空間波動関数 \(\psi(r_1,r_2)\) は反対称（\(\psi(r_2,r_1)=-\psi(r_1,r_2)\)）

電子2個の全波動関数は必ず反対称です。したがって、スピン部分が反対称なら空間部分は対称、スピン部分が対称なら空間部分は反対称、と「帳尻を合わせる」必要があります。この対応が後の角運動量 \(l\) の偶奇条件につながります。

4.3 相対運動と球面調和関数のパリティ（軌道角運動量 l との選択律）

ポテンシャルが相対座標 \(r=r_1-r_2\) にのみ依存する場合、空間波動関数は \(\psi(r_1,r_2)=U(R)u(r)\) と分離されます。ここで相対運動の波動関数 \(u(r)\) を3次元極座標 \((r,\theta,\phi)\) で表すと：

\[ u(r) = R_{nl}(r)\,Y_{lm}(\theta,\phi) \]
粒子の入れ替えが「−r」になるのはなぜ？

相対座標は \(r=r_1-r_2\) と定義されていました。粒子1と粒子2を入れ替えるということは、\(r_1\) と \(r_2\) の役割を入れ替えることなので、相対座標は \(r_1-r_2\) から \(r_2-r_1=-(r_1-r_2)=-r\) へと符号が反転します。つまり、「粒子の入れ替え」という操作は、相対座標の言葉では「原点を中心にベクトルを反対向きにする」（空間反転・パリティ変換）という、幾何学的にわかりやすい操作に対応しているのです。

ここで、粒子の入れ替え \(r_1\leftrightarrow r_2\) は、相対ベクトル \(r=r_1-r_2\) を \(-r\) へ変換する操作（空間反転／パリティ変換）に相当します。極座標における \(r\to -r\) の変換は：

\[ r\to r,\quad \theta\to\pi-\theta,\quad \phi\to\phi+\pi \]

球面調和関数 \(Y_{lm}(\theta,\phi)\) にこの変換を施すと、以下の数学的性質が成り立ちます：

\[ Y_{lm}(\pi-\theta,\phi+\pi) = (-1)^l\, Y_{lm}(\theta,\phi) \]

この結果から、相対軌道角運動量量子数 \(l\) に明確な許容条件が導かれます：

  • スピン1重項状態（空間対称）：\((-1)^l=+1\) である必要がある ⇒ \(l=0,2,4,\ldots\)（偶数のみ許される）
  • スピン3重項状態（空間反対称）：\((-1)^l=-1\) である必要がある ⇒ \(l=1,3,5,\ldots\)（奇数のみ許される）
この章のつながりをもう一度整理

全体の流れをたどると：①電子はフェルミオンなので全波動関数は必ず反対称 → ②全波動関数は空間部分とスピン部分の積なので、どちらか一方が対称でもう一方が反対称でなければならない → ③スピンの合成には1重項（反対称）と3重項（対称）の2種類がある → ④スピンの対称性が決まれば、辻褄を合わせるために空間部分の対称性も自動的に決まる → ⑤空間部分の対称性は、球面調和関数の性質 \((-1)^l\) を通じて、軌道角運動量 \(l\) が偶数か奇数かという条件に翻訳される、という流れになっています。1つの物理的要請（反対称性）が、スピンと軌道角運動量という一見無関係に見える2つの量子数を結びつけている点が、この章の面白いところです。

多電子原子の電子状態と電子配置

5.1 多電子原子のHamiltonianと独立粒子近似（Hartree近似）

原子番号 \(Z\) の原子（核電荷 \(+Ze\)、電子数 \(Z\)）の時間に依存しないSchrödinger方程式を考えます：

\[ \left[ \sum_{i=1}^{Z} \left( -\frac{\hbar^2}{2m_e}\nabla_i^2 - \frac{Ze^2}{4\pi\varepsilon_0 r_i} \right) + \sum_{i<j}^{Z} \frac{e^2}{4\pi\varepsilon_0 |r_i-r_j|} \right] \Psi = E\Psi \]
この長い式を項ごとに分解して読む

1つ目の和 \(\sum_i\left(-\dfrac{\hbar^2}{2m_e}\nabla_i^2 - \dfrac{Ze^2}{4\pi\varepsilon_0 r_i}\right)\)：これは「\(Z\)個の電子それぞれについて、運動エネルギーと、原子核（電荷 \(+Ze\)）からのクーロン引力によるポテンシャルエネルギーを足し合わせたもの」です。もし電子同士が互いに力を及ぼさなければ、この項だけで済み、各電子は独立な水素様原子の問題として扱えます。

2つ目の和 \(\sum_{i<j}\dfrac{e^2}{4\pi\varepsilon_0|r_i-r_j|}\)：これが問題を難しくしている「電子間の反発力」の項です。\(i<j\) という条件は、同じペアの電子間反発を2回数えないようにするためのものです（電子1と電子2の間の反発は1回だけ数える）。この項は、電子 \(i\) の位置が電子 \(j\) の位置に依存するため、各電子の運動を独立に解くことを不可能にしています。

第2項の電子間相互作用（電子間排斥力）が存在するため、この方程式は厳密に解くことができません。そこで、「各電子は、原子核の場と他の \((Z-1)\) 個の電子群が作る平均的なポテンシャル場 \(V(r_i)\) の中を独立に運動する」と仮定します。これを独立粒子近似（Hartree近似）と呼びます。これにより、複雑な多体問題が「1体の中心力ポテンシャル問題」へと還元されます。

Hartree近似のイメージ

たとえるなら、大勢の人が集まる部屋の中で、ある1人の人が「他の全員の位置を逐一気にする」代わりに、「他の全員が作り出す、部屋全体に広がる平均的な混雑具合」だけを気にして行動する、というイメージです。本当は全員が互いに影響し合っているのですが、その相互作用を「平均化」してしまうことで、1人1人の問題を独立に解けるようにしています。この近似のおかげで、多電子原子の問題は、各電子が「原子核＋他の電子が作る平均的な電場」という1つの中心力ポテンシャルの中を動く、水素原子に似た問題として扱えるようになります。

補足：なぜ多電子原子は急に難しくなる？

水素原子なら「電子と原子核」の2体問題なので、重心運動と相対運動へ分けられます。しかし電子がZ個になると、電子1と電子2、電子1と電子3……という電子間相互作用が大量に現れます。そこで、すべての電子同士の運動を同時に厳密に解く代わりに、各電子が「平均的な電場」の中を動くと近似します。

5.2 殻構造、軌道、およびエネルギー準位

中心力ポテンシャル \(V(r)\) の下では、各電子の状態は主量子数 \(n\)、方位量子数 \(l\)、磁気量子数 \(m\)、スピン磁気量子数 \(m_s\) の4つの量子数で指定されます。

水素原子ではエネルギー固有値が主量子数 \(n\) のみで決まりましたが、多電子原子では他の電子による遮蔽効果（Shielding Effect）のため、エネルギー固有値は \(n\) と \(l\) の両方に依存します（\(E=E(n,l)\)）。同じ \(n\) であっても、内殻へ浸透しやすい \(s\) 軌道（\(l=0\)）の方が、\(p\) 軌道や \(d\) 軌道よりも強い核電荷を感じるためエネルギーが低くなります（\(E_{ns} < E_{np} < E_{nd}\)）。

「遮蔽効果」と「軌道の浸透」を直感的に理解する

外側の電子から見ると、原子核の正電荷は、内側にいる他の電子たちの負電荷によって一部「隠されて」見えます。これが遮蔽効果です。たとえるなら、強い光源（原子核）の手前にすりガラス（内側の電子雲）を置くと、光が弱まって見えるようなものです。 ここで重要なのは、\(s\) 軌道（\(l=0\)）の電子は、実は原子核のごく近くまで入り込む確率がゼロではなく、他の \(p,d\) 軌道の電子に比べて「核に近づきやすい」性質（軌道の浸透）を持っている点です。核の近くに入り込めば入り込むほど、遮蔽の影響を受けにくく、より強い引力を感じます。そのため、同じ \(n\) の中でも \(s\) 軌道が一番エネルギーが低く（安定）、\(p,d,f\) と進むにつれてエネルギーが高くなっていくのです。

各方位量子数 \(l\) に対して、磁気量子数は \(m=-l,\ldots,0,\ldots,+l\) の \((2l+1)\) 個存在し、さらにスピンの自由度（\(m_s=\pm 1/2\)）の2倍があるため、1つの \((n,l)\) 軌道に入る最大電子数は \(2(2l+1)\) 個となります。

5.3 構成原理と電子配置の逆転（イレギュラー現象）

基底状態の原子では、エネルギーの低い軌道から順に電子が充填されていきます（構成原理／Aufbau Principle）。基本的には 1s → 2s → 2p → 3s → 3p と順調に埋まりますが、\(n\) が大きくなると軌道間のエネルギー差が小さくなり、エネルギー準位の逆転現象が発生します。

代表的なエネルギー逆転例：

  • 3p 軌道が埋まった後、次は 3d 軌道ではなく 4s 軌道に電子が入る（\(E_{4s} < E_{3d}\)）。
  • 4p 軌道が埋まった後、次は 4d 軌道ではなく 5s 軌道に電子が入る（\(E_{5s} < E_{4d}\)）。

※直感的な例え：「3階の奥にある部屋（3d）を借りるよりも、隣の建物の1階にある部屋（4s）を借りる方が移動エネルギーが小さくて済む」というイメージです。

演習問題9 の完全解法と詳細解説

演習問題9：問題文

水素原子のエネルギー固有値は主量子数 \(n\) だけで決まり、方位量子数 \(l\) にはよらない（磁気量子数 \(m\) によらないのは中心力系では共通）。一方、多電子原子系で見たように一般の中心力ポテンシャルの系ではエネルギーは \(l\) にも依存する。水素原子における「\(l\) に依存しない」性質は動径方向（\(r\)）の微分方程式のある特性が効いているが、一体何が肝（物理的・数学的本質）だったのか明らかにせよ。

6.1 問題背景と問われている本質の整理

一般的な3次元中心力ポテンシャル \(V(r)\) のもとでのSchrödinger方程式において、角度部分は常に球面調和関数 \(Y_{lm}(\theta,\phi)\) となり、エネルギーは磁気量子数 \(m\) には依存しません（空間回転対称性による \((2l+1)\)重の縮退）。しかし、通常は方位量子数 \(l\) が異なると動径方程式の遠心力ポテンシャル項が変化するため、エネルギー固有値は \(l\) に依存します。

なぜクーロン・ポテンシャル \(V(r)\propto -1/r\)（水素原子）の場合に限って、異なる \(l\) をもつ状態が奇跡的に偶然縮退（Accidental Degeneracy）して主量子数 \(n\) のみで決まるのか、その計算過程と構造を完全解明します。

補足：何を説明できれば問題9に答えたことになる？

「一般の中心力では \(l\) がエネルギーに効く」のに、「水素原子の \(-1/r\) ポテンシャルでは \(l\) が最終的なエネルギー式から消える」理由を、動径方程式→無次元化→級数展開→級数の打ち切り条件→主量子数 \(n\) の定義、という流れで示すことがポイントです。

6.2 動径Schrödinger方程式の導出と計算

3次元Schrödinger方程式

\[ \left[-\frac{\hbar^2}{2m}\nabla^2 + V(r)\right]\psi = E\psi \]

において、波動関数を

\[ \psi(r,\theta,\phi) = R(r)\,Y_{lm}(\theta,\phi) \]

と分離します。ここで \(u(r)\equiv rR(r)\) と変換すると、動径方向関数 \(u(r)\) に対する1次元形式のSchrödinger方程式が得られます：

\[ \left[-\frac{\hbar^2}{2m}\frac{d^2}{dr^2} + V_{\text{eff}}(r)\right]u(r) = E\,u(r) \]
なぜ u(r) = rR(r) と置き換えるのか

本来の動径方程式は \(R(r)\) に対して1階微分の項（\(\frac{2}{r}\dfrac{dR}{dr}\) のような項）を含む、少し扱いにくい形をしています。ところが \(u(r)=rR(r)\) という変数変換を行うと、その1階微分の項がきれいに消えて、通常の1次元Schrödinger方程式と全く同じ形（2階微分＋ポテンシャル）になります。これは数学的なテクニックですが、おかげで「3次元の中心力問題の動径方向」を「1次元の箱の中の粒子」と同じ手法で解けるようになる、という大きなメリットがあります。

ここで、実効ポテンシャル \(V_{\text{eff}}(r)\) は以下のように与えられます：

\[ V_{\text{eff}}(r) = V(r) + \frac{\hbar^2}{2m}\frac{l(l+1)}{r^2} \]

第2項 \(\dfrac{\hbar^2}{2m}\dfrac{l(l+1)}{r^2}\) は遠心力ポテンシャル（Centrifugal Potential）です。

「遠心力ポテンシャル」とは何か

古典力学で、円運動をしている物体には外向きの「遠心力」が働くように見えることを思い出してください。角運動量 \(l\) を持つ粒子が原子核のまわりを回っている（ように振る舞う）とき、量子力学でもこれと似た効果が現れます。それが \(\dfrac{\hbar^2}{2m}\dfrac{l(l+1)}{r^2}\) という項で、原点（\(r=0\)）に近づくほど急激に大きくなり、粒子が原子核に近づくのを妨げるように働きます。\(l=0\)（\(s\)軌道）のときはこの項がゼロになるため、粒子は原子核のごく近くまで自由に入り込めます。これが先ほど5.2節で触れた「\(s\)軌道の浸透性」の数学的な起源です。\(l\) が大きいほど遠心力ポテンシャルの壁が高くなり、粒子は原子核から遠ざけられます。

水素原子の場合、\(V(r)=-\dfrac{e^2}{4\pi\varepsilon_0 r}\) です。無次元の変数へ変換するため、ボア半径 \(a_0 = \dfrac{4\pi\varepsilon_0\hbar^2}{me^2}\) を導入し、\(\rho=2\kappa r\)（ただし \(\kappa=\dfrac{\sqrt{-2mE}}{\hbar}\)）とおくと、動径方程式は次の連体ラゲール微分方程式に変換されます：

なぜわざわざ無次元変数 ρ に変換するのか

\(r\) は長さの単位（メートルなど）を持つ変数ですが、これをそのまま使って方程式を解こうとすると、\(\hbar, m, e, \varepsilon_0\) といった物理定数が式のあちこちに残ってしまい、数学的な構造が見えにくくなります。そこで \(\rho=2\kappa r\) という「単位を持たない（無次元の）」変数に置き換えることで、物理定数を \(\lambda\) という1つのパラメータにまとめてしまい、方程式の形を純粋に数学的な問題（級数展開で解ける形）に整理することができます。これは物理でよく使われる常套手段で、複雑な問題ほど「本質的な自由度がいくつあるか」を見抜くために無次元化が有効です。

\[ \frac{d^2u}{d\rho^2} + \left[ \frac{\lambda}{\rho} - \frac{1}{4} - \frac{l(l+1)}{\rho^2} \right]u = 0 \]

ここで、パラメータ \(\lambda\) は

\[ \lambda = \frac{e^2}{4\pi\varepsilon_0\hbar}\sqrt{\frac{m}{-2E}} \]

6.3 級数解法による量子化条件と「肝」の導出

これから何をするのか、先に全体の流れをつかもう

この節でやることは、大きく分けて4つのステップです。 (1) まず \(\rho\to\infty\) と \(\rho\to0\) それぞれで方程式がどう振る舞うか（漸近挙動）を調べ、その振る舞いを予め関数の形に織り込んでおく。 (2) 残った「よくわからない部分」\(v(\rho)\) を、べき級数（\(\rho\) の1次、2次、3次…の項を無限に足し合わせたもの）として表す。 (3) 級数の係数 \(c_k\) 同士の関係（漸化式）を求める。 (4) 波動関数が物理的に意味を持つためには、この無限級数がどこかで「打ち切られて」有限の多項式にならなければならないことを示し、そこから量子化条件（エネルギーが飛び飛びの値しか取れないという条件）を導く。 この「級数が打ち切られる」という要請こそが、水素原子のエネルギーが離散的な値 \(E_n\) になる理由そのものです。

漸近挙動（\(\rho\to\infty\) で \(u(\rho)\sim e^{-\rho/2}\)、\(\rho\to 0\) で \(u(\rho)\sim \rho^{l+1}\)）を考慮して、

\[ u(\rho) = \rho^{l+1} e^{-\rho/2} v(\rho) \]
この置き換えが意味すること

\(\rho\to\infty\)（原子核から遠く離れた場所）では、波動関数は \(e^{-\rho/2}\) のようになめらかに減衰していかなければ、粒子が無限遠まで存在してしまい、物理的に意味を持ちません（存在確率が発散してしまいます）。 一方 \(\rho\to0\)（原子核のごく近く）では、遠心力ポテンシャルの影響で波動関数は \(\rho^{l+1}\) のようにゼロに近づかなければなりません（\(l\) が大きいほど、原子核に近づきにくいことに対応します）。 そこで \(u(\rho)\) を、この2つの「境界での正しい振る舞い」をあらかじめ掛け合わせた形 \(\rho^{l+1}e^{-\rho/2}\) と、まだ分かっていない残りの関数 \(v(\rho)\) の積として書くことで、\(v(\rho)\) が比較的単純な（多項式に近い）関数になることが期待できます。

と置き、\(v(\rho)\) を冪級数

\[ v(\rho) = \sum_{k=0}^{\infty} c_k \rho^k \]

として展開します。これを微分方程式に代入して各次の係数を比較すると、以下の漸化式（Recurrence Relation）が得られます：

\[ c_{k+1} = \frac{k+l+1-\lambda}{(k+1)(k+2l+2)}\, c_k \]
「漸化式」と「打ち切り」の意味

この漸化式は、「係数 \(c_{k+1}\) は、1つ前の係数 \(c_k\) に、ある比率をかけたもの」であることを示しています。つまり \(c_0\) が決まれば、この式を繰り返し使うことで \(c_1,c_2,c_3,\ldots\) が芋づる式にすべて決まっていきます。 もしこの数列が無限に続いてしまうと（つまり係数が永遠にゼロにならないと）、\(v(\rho)\) は \(\rho\to\infty\) で \(e^{\rho}\) のように爆発的に増加してしまうことが数学的に示せます（\(e^{-\rho/2}\) と打ち消し合わずに、むしろ発散してしまう）。これでは波動関数が物理的に許されません。 そこで、ある有限のところ（\(k=N\)）で係数がゼロになり、それ以降の係数もすべてゼロになって級数が「多項式」として打ち切られることが必要になります。漸化式の分子部分 \((k+l+1-\lambda)\) がゼロになれば、その瞬間から先の係数は連鎖的にすべてゼロになるので、これが打ち切り条件です。

波動関数が物理的に許容されるため（\(\rho\to\infty\)で発散せず自乗可積分であるため）には、この級数が途中の最高次数 \(k=N\)（\(N=0,1,2,\ldots\)を動径量子数という）で打ち切られて多項式にならなければなりません。打ち切り条件は、分子が0になることです：

\[ N+l+1-\lambda = 0 \quad \Rightarrow \quad \lambda = N+l+1 \]

ここで、主量子数（Principal Quantum Number）\(n\) を次のように定義します：

\[ n \equiv N+l+1 \qquad (n=1,2,3,\ldots) \]
動径量子数 N と主量子数 n の関係を直感的に

\(N\)（動径量子数）は、波動関数の「動径方向のふくらみやくびれ（節）」の数に対応する整数です。\(N\) と \(l\)（軌道の形を決める角運動量の量子数）という、本来は全く別の起源を持つ2つの整数が、水素原子の場合に限って \(n=N+l+1\) というシンプルな和の形で結びつき、1つの整数 \(n\) にまとまってしまう、というのがここでの驚くべき発見です。次のステップで、まさにこの \(n\) だけがエネルギーを決めることを見ていきます。

パラメータ \(\lambda\) が正の整数 \(n\) に等しくなければならないという条件から、エネルギー固有値 \(E\) を解き明かします：

\[ \lambda = \frac{e^2}{4\pi\varepsilon_0\hbar}\sqrt{\frac{m}{-2E}} = n \] \[ \Rightarrow \quad -2E = \frac{m}{\hbar^2}\left[\frac{e^2}{4\pi\varepsilon_0}\right]^2 \frac{1}{n^2} \] \[ E_n = -\frac{me^4}{32\pi^2\varepsilon_0^2\hbar^2}\cdot\frac{1}{n^2} \]

6.4 結論：何が「肝」であったのか？（物理的・数学的理由のまとめ）

結論を理解する前に：何が「特別」だったのかを振り返る

一般の中心力ポテンシャル \(V(r)\) では、動径方程式の中の \(V(r)\) の形に応じて \(N\) と \(l\) が別々にエネルギーへ影響を与え、\(N\) と \(l\) の値が違えば普通は異なるエネルギーになります。 しかし水素原子のクーロンポテンシャル \(V(r)=-e^2/(4\pi\varepsilon_0 r)\) の場合だけ、計算の中に現れるパラメータ \(\lambda\) が \(N\) と \(l\) の「和」\(n=N+l+1\) だけに依存する、という特殊な構造を持っていました。エネルギー \(E_n\) は結局 \(\lambda(=n)\) だけで決まるので、\(N\) と \(l\) の内訳（たとえば \(N=2,l=0\) でも \(N=1,l=1\) でも \(N=0,l=2\) でも、和が同じ \(n=3\) であれば）が違っても、同じエネルギーになってしまうのです。以下では、この現象が起きる理由を「数学的な理由」と「物理的な理由」の2つの側面からまとめます。

肝となる数学的・物理的理由の要約
